# ScreenMotion prototype assets

The starter uses four generated background images in `assets/wallpapers`.

The app adds the interactive layer at runtime; the image itself is intentionally static.

## Generation directions

**Neon vehicle**
Cinematic vertical wet highway at night, futuristic generic sports car, neon city reflections, no logos, no text, strong depth, clean center/bottom subject-safe region.

**Aquarium**
Photorealistic vertical coral reef, blue sun rays, detailed rocks and corals, moderate fish density, open water areas for runtime fish overlays, no text.

**Space**
Vertical cinematic planet and nebula, asteroid field, deep star field, open central flight corridor for runtime spacecraft, no text.

**Nature**
Vertical alpine lake, mountains, forest, golden-hour light, calm water reflection, foreground rocks, open sky for runtime birds, no text.

Production assets should be regenerated at 1440×3200+ and separated into depth layers.
